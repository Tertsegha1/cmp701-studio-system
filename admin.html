📦 Blackboard Bundle — Self-Contained Files
Use this every week. Generates three standalone HTML files with the config embedded inside — no external dependencies, no blocked URLs. Upload all three to Blackboard Course Files and replace the old versions.

⬇ index.html — Student Dashboard ⬇ admin.html — Admin Panel ⬇ tutor.html — Tutor View
Blackboard upload steps (each Monday):
1. In your Blackboard Ultra course → Course Files → studio-system folder
2. Select the old index.html → Replace File → upload new index.html
3. First time only: also replace admin.html and tutor.html
4. Students see the update immediately on next load — no cache issues
